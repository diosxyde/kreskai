# Kreskaï

Mes séances de sport et mon alimentation, 100 % sur mon téléphone : aucune donnée envoyée, aucun pisteur.

Appli : https://diosxyde.github.io/kreskai/

## Sécurité
CSP stricte (meta), filtre anti-XSS sur tout HTML injecté, JSON assaini à la lecture et à la restauration, service worker limité aux fichiers connus, anti-iframe, pas de référent envoyé. Aucune donnée ne quitte le téléphone, sauf la recherche de code-barres vers Open Food Facts.
